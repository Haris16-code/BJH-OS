Key Features in BJH OS 4.6
Draggable App Windows: Apps now open inside floating, draggable iframe windows with a titlebar and close button.
Maximize / Restore: Windows can be maximized or restored (double‑click titlebar works too).
In‑window Launching: Start menu and toolbar apps open inside windows instead of new tabs.
window.open Intercept: Same‑origin window.open() calls open in a window automatically.
Programmatic API: Use window.openAppInWindow(url, title) from scripts to open windows.
UX Improvements: Smoother window chrome, shadowing and drag behavior.
