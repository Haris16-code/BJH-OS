# BJH OS Changelog

## 4.7 — New Apps Market Launch
**Release Date:** 30 November 2025  
**Type:** Major Update — Worldwide Rollout

---

## 🚀 What's New: BJH OS 4.7 — The Apps Market is Live!

The all-new **BJH OS Apps Market** is officially available in the 4.7 update!  
Explore, download, rate, and promote apps and games like never before.

---

### 🎉 Apps Market Features
- **Main Apps Page**
  - Browse all apps and games with a clean UI.
  - Smart tabs: **Games**, **Apps**, **Search**.
  - App cards show: **icon, name, category, rating, downloads**.

- **Search System**
  - Autocomplete suggestions while typing.
  - Fast and accurate results.

- **Trending Notifications**
  - Highlight trending apps with URL and preview image.

- **App Detail Page**
  - Icon, name, developer/company.
  - Rating, reviews, download size.
  - **Download button** with version info.
  - Screenshots & video previews (first media auto-displays).
  - “About This App/Game” description.
  - Ratings & Reviews with **Helpful / Not Helpful** counters.
  - Similar apps/games shown at the bottom.

---

### 👤 User Features
- Create a **BJH OS account** or login to access the Apps Market.
- Save favorite apps in profile.
- All downloads appear in **Manage Apps** panel.
- Download newest apps instantly.
- **Auto-update** apps when new versions release.
- Rate and review apps.
- Password reset & recovery system.
- Email notifications for:
  - Registration
  - App updates
  - Promotions

---

### 🛠️ Developer Features
- Upload apps and games with:
  - Icon  
  - Name  
  - Description  
  - Screenshots / Videos  
  - Category  
  - Version  
  - ZIP file  
- Submit updates for already published apps.
- View full app stats:
  - Downloads  
  - Ratings  
  - Reviews  
- Comment on user reviews.
- Manage **promotion points** to boost visibility.
- Notifications for:
  - Approvals  
  - Rejections  
  - Promotions  
- Provide support details (website, email, etc.).
- Submit appeals when needed.
