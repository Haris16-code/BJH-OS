# Security Policy

## Supported Editions

BJH OS provides security support for the following editions:

- **BJH OS Self-Hosted** – runs locally on your system.  
- **BJH OS Web Edition** – runs entirely in the browser, no download required.

---

## Reporting a Vulnerability

If you discover a security vulnerability in BJH OS, please report it responsibly.  

**How to report:**
- Send a detailed report to **[https://github.com/Haris16-code/BJH-OS/issues](https://github.com/Haris16-code/BJH-OS/issues)**.  
- Include the following information:
  - Steps to reproduce the vulnerability
  - Affected edition (Self-Hosted or Web Edition)
  - Screenshots or proof-of-concept (if applicable)

**What to expect:**
- We will acknowledge your report promptly.  
- Updates will be provided on the investigation and resolution timeline.  
- Once resolved, you may be credited in release notes unless you request anonymity.  

**Important:** Do not publicly disclose the vulnerability until it has been fixed to protect users.
