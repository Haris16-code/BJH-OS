BJH OS Developer Guide

Developer API Reference

BJH OS exposes a global BJH object. Use these methods to interact with the file system.

  • BJH.ls(folderId): Returns array of items in folder.
  • BJH.cat(fileId): Returns file content.
  • BJH.touch(name, content): Creates new file.
  • BJH.mkdir(name): Creates new folder.
  • BJH.rm(id): Deletes item.

User Guide

Media Player: Opening audio, video, or image files will launch the BJH OS Media Player in a new window.

Drag & Drop: Drag files internally to move. Drag from desktop to upload.

Source Code: Click the "Source Code" button in the toolbar to view the GitHub repository.
